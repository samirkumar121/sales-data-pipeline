# Sales Data Pipeline

A simple Data Engineering project demonstrating ETL concepts using Python, Pandas, SQLite, Git, and GitHub Actions.

## Features

- Extract data from multiple CSV files
- Data Quality Checks
- Data Cleaning & Transformation
- Incremental Loading
- SQLite Storage
- Logging
- Automated Testing

## Tech Stack

- Python
- Pandas
- SQLite
- Pytest
- Git
- GitHub Actions

## Run Project

```bash
pip install -r requirements.txt
python main.py
